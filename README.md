# FixTude

MVP iniziale del SaaS FixTude.

## Funzioni attuali

- Landing page
- Accesso separato per Privato/Debitore
- Accesso separato per Risolutore/Professionista
- Login demo
- Dashboard distinta per ruolo
- Logout
- Struttura pronta per essere estesa con database, caricamento documenti e AI

## Avvio locale

```bash
pip install -r requirements.txt
python app.py
```

Aprire:
http://127.0.0.1:5000
